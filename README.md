# Co-Driver Chaos

Гонка по замыслу Shadow: один пилотирует болид, напарник разыгрывает карты -
улучшения и пакости НА СВОЕГО ЖЕ водителя (минус колесо, скример макаки,
нитро, масляная лужа...). Отдельный режим - пакости соперникам.

Код, графика и звук свои (процедурные), three.js r160 по лицензии MIT (lib/).
Чужой код и ассеты не использовались.

## Реванш (rematch)
После финиша хост видит «ЕЩЁ ГОНКУ» — полный сброс гонки (болиды на старт, энергия/руки экипажей, погода, эффекты) и новая рассылка start всем экипажам. Гостям показывается «Хост решает — новый заезд начнётся автоматически…»; сброс применяется только из состояния finished, дублированный start mid-race прогресс не стирает.

## Запуск
Требуется Node.js 22 (проверено на v22.23.3). Библиотеки ставить не нужно -
three.js лежит в lib/, зависимостей из npm нет.
```
node server.js                 # по умолчанию порт 8080
PORT=8319 node server.js       # если 8080 занят (порт 8319 проверен 26.10)
```
Открыть http://localhost:8080 (или свой порт).


## Как позвать друга (проверено 26.10)
Один игрок всегда хост: node server.js, дальше два пути. Честный статус проверки 26.10: оба пути проверены с тестовых клиентов внутри одной машины (сервер отвечает на своём IP и хост+гость вошли в комнату через туннель, команда старта дошла); подключение с отдельного физического устройства и полная гонка через интернет НЕ прогонялись - это smoke-тест транспорта, не гарантия интернет-матча.

Публичного сервера у игры НЕТ и не предполагается: всё работает локально на
машине хоста, ниже два пути подключения друзей. Публикация в интернет
(хостинг, постоянный туннель) сознательно не настраивалась.

1. ОДНА WI-FI СЕТЬ (основной путь). Сервер слушает все интерфейсы (проверено:
   отклик по IP хоста, не только localhost). Хост узнаёт свой IP и диктует друзьям
   http://<IP-хоста>:8080 + код комнаты. Телефоны в той же сети подключаются так же.
2. ИНТЕРНЕТ ЧЕРЕЗ БЕСПЛАТНЫЙ ТУННЕЛЬ (без аккаунта, проверено сквозным тестом
   26.10: хост и гость подключились через публичный https-адрес, зашли в комнату,
   команда старта от хоста дошла до гостя по защищённому websocket):
     npx -y localtunnel --port 8080
   Хост отправляет друзьям напечатанный адрес вида https://xxxx.loca.lt + код.
   Туннель запускается вручную на время игры и закрывается после (Ctrl+C);
   он не прописан в автозапуск и не является постоянным публичным адресом.
   Ограничения честно: это сторонний бесплатный сервис, он может показать
   промежуточную страницу перед входом, менять поведение или быть недоступен;
   полная гонка через туннель на нагрузке не тестировалась - при любой проблеме
   надёжный вариант всегда пункт 1 (одна сеть) или игра за одним экраном.

## Режимы
- СОЛО + АВТО-НАПАРНИК - карты разыгрывает ИИ-напарник
- ВДВОЁМ НА ОДНОМ ЭКРАНЕ - водитель на стрелках/WASD, напарник на 1/2/3
- СЕТЬ (до 12 участников, экипажи) - хост водит болид №1 и считает гонку:
  1. Хост запускает node server.js, открывает http://localhost:8080, жмёт СОЗДАТЬ СЕТЕВУЮ ГОНКУ и диктует код комнаты.
  2. Остальные открывают http://<IP-хоста>:8080, жмут ПОДКЛЮЧИТЬСЯ ПО КОДУ и вводят код.
  3. Роли раздаются автоматически в порядке подключения: 1-й гость - напарник
     болида №1, 2-й - ВОДИТЕЛЬ болида №2, 3-й - напарник болида №2 и т.д.
     (всего 6 болидов x 2 места = 12 участников). Кто подключился позже -
     зрители на болиде №1. Гонка стартует при подключении первого гостя,
     остальные подхватываются на ходу.
  4. Гость-водитель рулит своим болидом (стрелки/WASD/тач) - ввод уходит хосту,
     хост считает физику. Пока ввод не приходит, болидом управляет ИИ.
  5. Карты: у каждого экипажа СВОЯ рука и СВОЯ энергия; напарник играет карты
     на болид своего экипажа.

## Управление
- Руль: стрелки или A/D, газ Up/W, тормоз Down/S, P - пит-стоп
- Карты: 1/2/3 или клик/тап по карте. Энергия копится сама и за обгоны.
- Телефон/планшет: видимые зоны на экране - левая/правая стрелки = руль,
  центр = тормоз, газ автоматический. Жёлтой стрелкой сверху отмечен СВОЙ болид.

## Известные ограничения
- Сеть проверена только на localhost. Доступ с другого устройства по IP
  (роутер/NAT/файрвол/телефон) НЕ проверен - зависит от вашей сети. Оба игрока
  должны быть в одной сети (или проброс порта).
- Сетевые роли: автоматические, по порядку входа (лобби с выбором болида и
  имён НЕТ). Задержка ввода гостя-водителя не измерена (localhost ~мгновенно,
  по реальной сети зависит от пинга). Если гость-водитель молчит дольше ~1.5с
  (лаг, пауза, отвал), болид ВРЕМЕННО ведёт ИИ до возобновления ввода -
  это отдельный режим от ручного управления: пока человек шлёт ввод,
  рулит только он (доказано A/B-тестом выше). Конфигурация 6 болидов/12 мест - временная,
  выбрана разработчиком, число игроков пользователь не задавал.
- Производительность измерена только в программном рендере без GPU (SwiftShader):
  3-5 кадров/с. На реальном железе с GPU будет быстрее, но цифры нет - не измерено.
- Звук процедурный (WebAudio) - в headless-тестах не проверялся, слушать живьём.
- Тач: синтетический браузерный автотест ?shot=touch - 10/10 PASS (руль
  влево/вправо, тормоз, тап по карте, HUD-зоны не рулят, макака не блокирует).
- Болид крупно с ракурсов: ?shot=carview&car=N&angle=ГРАД&pitch=ГРАД
  (студийный вид без HUD; car=0..5 по командам GreenFox..Inferno).
  Тест синтетический (события инжектятся кодом), НА ЖИВОМ ТЕЛЕФОНЕ не гонялось.
