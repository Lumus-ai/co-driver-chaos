CO-DRIVER CHAOS — КАК ЗАПУСТИТЬ (для Shadow)
=============================================

ЧТО НУЖНО
- Компьютер с Node.js. Проверено на Node.js 22; более ранние версии НЕ
  запускались (код использует только встроенные модули Node, но другие
  версии не проверялись).
  Скачать: https://nodejs.org  (кнопка LTS, установка по умолчанию).
- npm install НЕ нужен: внешних зависимостей нет, всё внутри архива.
- Интернет НЕ нужен: игра работает в локальной сети (Wi-Fi). Проверено
  с полностью отключённым внешним доступом и чистым браузером без кэша:
  Three.js и все ресурсы лежат внутри архива, ничего не тянется с CDN.
- Аккаунты, регистрации, OAuth — не нужны.

ЗАПУСК НА КОМПЬЮТЕРЕ (хост)
1. Распакуй архив с игрой в любую папку.
2. В терминале (командной строке) в этой папке:
     node server.js
3. Открой в браузере:  http://localhost:8080
   (проверено на распакованном архиве: запуск без переменных окружения
   слушает именно порт 8080)
4. Нажми «СОЗДАТЬ СЕТЕВУЮ ГОНКУ» — получишь код из 4 букв.

ОДИН ИГРОК (проверить одному)
- На главном экране выбери «СОЛО + АВТО-НАПАРНИК» — водитель + ИИ-напарник.

ИГРА ВДВОЁМ И БОЛЬШЕ (телефон)
1. Телефон должен быть в ТОМ ЖЕ Wi-Fi, что и компьютер.
2. Узнай IP компьютера:
   - Windows: ipconfig  → строка «IPv4-адрес», например 192.168.1.50
   - Mac/Linux: ifconfig или ip addr → inet 192.168.x.x
3. На телефоне открой:  http://192.168.1.50:8080  (подставь свой IP)
4. Нажми «ПОДКЛЮЧИТЬСЯ ПО КОДУ» и введи 4-буквенный код комнаты.
5. Роли раздаёт ПОРЯДОК ПОДКЛЮЧЕНИЯ: первый гость — напарник болида №1,
   второй — водитель болида №2, третий — напарник болида №2 и т.д.
   Хост всегда водитель болида №1 и начинает гонку.

УПРАВЛЕНИЕ
- Водитель: стрелки / WASD, на телефоне — тач-зоны руля и ТОРМОЗ (держи телефон горизонтально; кнопка ⛶ вверху включает полный экран, если браузер это поддерживает).
- Напарник: карты внизу экрана, тап по карте (или клавиши 1/2/3) —
  карта применяется к ТВОЕМУ болиду (усиления и пранки на своего водителя).

ЕСЛИ ЧТО-ТО НЕ ТАК
- Порт 8080 занят: запусти так:  PORT=3000 node server.js  (Linux/Mac)
  или  set PORT=3000 && node server.js  (Windows cmd).
- Телефон не видит игру: проверь, что оба в одном Wi-Fi, и что
  брандмауэр разрешил Node.js (Windows спросит при первом запуске — «Разрешить»).

ИЗВЕСТНЫЕ ОГРАНИЧЕНИЯ (честно)
- Полный список — в README.md. Главное: гонялось в браузерах на одном
  компьютере; на живом телефоне пока не проверено — первый запуск с
  телефона будет первым реальным тестом тача.
